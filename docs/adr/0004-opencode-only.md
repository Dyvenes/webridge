# ADR 0004: Только opencode, только API

## Решение

WebBridge предоставляет локальный OpenAI-совместимый API и не содержит
собственного чат-клиента, агентного цикла или исполнителя инструментов.
Единственный поддерживаемый клиент — opencode V2.

## Обоснование

- opencode уже отвечает за контекст, сессии, compaction, permissions и
  выполнение инструментов. Дублировать это в мосте — источник расхождений.
- Мост должен оставаться тонким: принять OpenAI-запрос, проиграть его в
  веб-чате, вернуть ответ и `tool_calls`.
- Поддержка Aider/Cline и собственного UI распыляет усилия и не нужна для
  основного сценария.

## Последствия

- `docs/clients.md` описывает только opencode.
- В README нет обещаний собственного агентного цикла.
- `webbridge doctor`, `smoke` и другие команды могут добавляться как
  диагностика API, но не как замена клиенту.
- Плагин opencode — единственное место, где добавляются заголовки сессий.
