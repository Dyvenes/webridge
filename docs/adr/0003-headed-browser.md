# ADR 0003: Headed-браузер на старте

## Решение
На M0–M3 используется headed-браузер (`headless: false`).

## Обоснование
DeepSeek — крупный сервис с антибот-защитой; headed-режим снижает риск капчи и блокировки (PROJECT.md §8.8). Переход на headless — только после стабильной работы.

## Последствия
На M1 `login` и `doctor` запускают видимое окно; это ожидаемое поведение, а не баг.
