# ADR 0001: Первый сервис — DeepSeek

## Контекст
Нужно выбрать веб-сервис для первого адаптера.

## Решение
Первый сервис — **chat.deepseek.com**.

## Обоснование
- Веб-чат бесплатен, нет платной подписки[reference:11].
- Есть публичные сведения о DOM-селекторах (#chat-input и др.)[reference:12].
- API платный, что делает веб-чат экономически осмысленным для WebBridge[reference:13].

## Последствия
- ToS-риск средний: запрещены боты для спама/обхода лимитов, но не любая автоматизация[reference:14].
- Бюджеты в конфиге — консервативные (25/час, 200/день).
