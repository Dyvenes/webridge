# deepseek — заметки о ToS и лимитах

**Статус:** заполнено, риск оценён.  
**Дата проверки:** 2026-10-30.  
**Сервис:** chat.deepseek.com (веб-чат; API — отдельный продукт).

## 1. ToS и автоматизация

- Прямого запрета на **автоматизацию браузера** в пользовательском соглашении веб-чата нет, но есть формулировки, которые можно трактовать как ограничение:
  - «Probing for vulnerabilities or circumventing the intended use limitations (like using bots or scripts to spam the service) is prohibited»[reference:0].
  - Запрещено использование «robots, spiders, or similar programs» для массового сбора/зеркалирования контента сервиса[reference:1].
- **Вывод:** WebBridge не спамит и не собирает контент массово, но работает через бота. Риск ограничения аккаунта есть. Рекомендация из PROJECT.md §2.1: не подключать основной аккаунт, от которого зависит критичная работа, до оценки риска.

## 2. Лимиты подписки

- Веб-чат DeepSeek **бесплатен**; отдельной платной подписки на веб-чат нет[reference:2].
- Официальных опубликованных суточных/часовых квот на сообщения нет (по состоянию на 2026-10), но:
  - разные источники упоминают практические ограничения порядка **30 запросов в час** или **30 запросов в день** для бесплатного веб-чата[reference:3][reference:4];
  - DeepSeek оставляет за собой право «impose limits on certain features or restrict access» без предварительного уведомления[reference:5].
- **Практический вывод для конфига:** закладывать консервативные бюджеты: `max_requests_per_hour: 25`, `max_requests_per_day: 200`. Точные цифры уточнять экспериментально на M1/M5.

## 3. Риск блокировки

- **Средний.** DeepSeek — крупный сервис с антибот-защитой; агрессивная автоматизация может привести к капче или временной блокировке.
- Митигации: headed-браузер, постоянный профиль, паузы, один чат на аккаунт, остановка при капче (см. PROJECT.md §2.1, §8.8).

## 4. API vs веб-чат

- API DeepSeek платный (per-token), веб-чат — бесплатный. WebBridge использует именно **веб-чат**, чтобы не платить за токены[reference:6].
- Это не отменяет ToS-риска, но объясняет экономический смысл проекта.
